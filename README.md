# Лабораторная работа №1. Data Understanding

## Описание
Первичный анализ датасета Sample - Superstore (e-commerce sales).
Аудит качества данных: пропуски, дубликаты, выбросы, мини-EDA.

## Структура проекта
- `notebooks/01_data_understanding.ipynb` — основной ноутбук
- `data/Sample - Superstore.csv` — исходный датасет
- `report/quality_report.md` — текстовый отчёт
- `.gitignore` — исключения для Git

## Как запустить
1. Открыть ноутбук в Colab или Jupyter.
2. Загрузить CSV в `/content/data/`.
3. Выполнить все ячейки сверху вниз.

## Зависимости
pandas, numpy, matplotlib, seaborn
